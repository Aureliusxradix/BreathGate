# Licence

BreathGate is free software under the **GNU General Public License v3.0** — ruled 2026-08-14.

The reasoning, kept because it is the point rather than a formality: this app was ruled a **gift**.
A permissive licence would let anyone wrap it, add the telemetry it deliberately refuses, and sell
it back. **Copyleft is what makes "the gift cannot be owned" legally operative instead of merely
stated.** Anyone may use, study, change and share this — and anyone who distributes a changed
version must pass the same freedom on.

The invariant this licence protects in practice: **there is no `INTERNET` permission, and a fork
that adds one is a different program wearing this one's clothes.**
